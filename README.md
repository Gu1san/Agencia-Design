# Sobre
Este projeto consiste em uma página de uma agência de design fictícia chamada Vértice Design.
O objetivo é passar a essência da empresa através da estilização e conteúdo da página.

## Performance
Uma das melhorias implementadas foi a otimização do site, que apesar de já estar boa inicialmente, tinha espaço para melhorias. 

### Antes
Os fatores que mais estavam impactando a performance eram as imagens, tanto pela forma de carregamento quanto os arquivos em si.
